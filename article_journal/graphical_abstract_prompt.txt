GRAPHICAL ABSTRACT — Marine Race Arena
Target: Robotics and Autonomous Systems (Elsevier)
Deliverable: one single-panel image, landscape, 1328 x 531 px minimum
(Elsevier requirement), vector source preferred (PDF/SVG), 300 dpi if raster.

=====================================================================
SCIENTIFIC MESSAGE THE IMAGE MUST CARRY
=====================================================================
One idea, stated visually: in Marine Race Arena the autonomy stack and the
scorer see different worlds, and that separation is what makes underwater
racing results comparable.

A reader who looks at this image for five seconds must come away with:
  (1) an underwater vehicle racing through an ordered sequence of gates;
  (2) the controller receives ONLY onboard sensing plus acoustic beacon
      packets;
  (3) a separate referee receives privileged simulator truth and produces the
      official result;
  (4) NO arrow ever goes from the referee back to the controller.

If a viewer could plausibly believe the referee tells the controller which gate
is next, the figure has failed.

=====================================================================
LAYOUT — three horizontal bands, left to right
=====================================================================

LEFT BAND (~34% width) — "THE RACE"
  A stylised underwater scene, cool blue gradient, lighter at the top,
  sandy seabed at the bottom.
  A BlueROV2-style ROV (dark frame, two pale-blue buoyancy tubes, visible
  thrusters) in three-quarter view, moving left to right.
  Four to five square gate frames receding into depth along a gently curving
  path, numbered G1, G2, G3 ... with a small beacon dot on the top bar of each,
  labelled B01, B02, B03.
  A thin dashed path line threads through the gate apertures in order.
  Two faint concentric arcs radiate from the beacon nearest the vehicle,
  suggesting acoustic transmission.
  Small header, upper left: "Ordered underwater gate course".

MIDDLE BAND (~33% width) — "TWO VIEWS OF THE SAME RUN"
  Two clearly separated stacked boxes, with an unmistakable gap between them.

  UPPER BOX — teal/blue outline, label "CONTROLLER SEES" (all caps, small):
      camera icon      -> "forward camera"
      wave icon        -> "acoustic beacon packets"
      gauge icon       -> "depth, IMU, DVL"
      envelope icon    -> "teammate messages (optional)"
    A single thick teal arrow leaves the right edge of this box, labelled
    "surge / sway / heave / yaw", and returns to the vehicle in the LEFT band
    (curving back beneath the middle band, or drawn as a return arrow along the
    bottom). This closes the control loop visually.

  LOWER BOX — amber/orange outline, label "REFEREE SEES" (all caps, small):
      crosshair icon   -> "global pose"
      gate icon        -> "exact gate geometry"
      shield icon      -> "collisions, bounds"
      stopwatch icon   -> "official timing"

  BETWEEN THE TWO BOXES: a vertical dashed grey separator running the full
  height of the band, with a small padlock glyph at its centre and the caption
  "information boundary" set vertically or immediately beneath the padlock.
  Optionally, one thin red arrow pointing from the lower box up toward the
  upper box, crossed out with a small red X — but ONLY if it reads instantly as
  "forbidden"; if there is any ambiguity, omit it and keep the padlock alone.

RIGHT BAND (~33% width) — "OFFICIAL RESULT"
  An amber-outlined card headed "INDEPENDENT REFEREE", containing a compact,
  clean mock result table with four rows:
      gates          51 / 51
      collisions          0
      out of bounds       0
      status      FINISHED
  Below the card, three small pill-shaped badges in a row:
      "3 circuits"   "9 / 9 runs"   "0 events"
  Beneath the badges, one line of small text:
      "onboard-only completion, currents disabled"

=====================================================================
ARROWS — exhaustive list. Draw these and nothing else.
=====================================================================
  A. vehicle sensors  ->  CONTROLLER SEES box        (teal, solid)
  B. CONTROLLER SEES  ->  vehicle (command)          (teal, solid, thick)
  C. simulator truth  ->  REFEREE SEES box           (amber, solid)
  D. REFEREE SEES     ->  OFFICIAL RESULT card       (amber, solid)

FORBIDDEN — must not appear under any circumstance:
  - any arrow from REFEREE SEES to CONTROLLER SEES
  - any arrow from OFFICIAL RESULT back into the left or middle band
  - any arrow from exact gate geometry into the controller path
  - any shared box, shared icon or shared background tint that visually merges
    the teal group with the amber group

=====================================================================
COLOUR AND STYLE
=====================================================================
  Controller / autonomy group  : teal-blue   #2F6DB0
  Referee / evaluation group   : warm amber  #E07B39
  Ink, text, outlines          : near-black  #12263A
  Underwater scene             : blues #3E8FC4 to #8FC7E8, seabed #E4D8BE
  Neutral separator / grey     : #9AA7B4
  Background                   : white or very light #F7F9FB

  Flat vector illustration, thin uniform strokes (1.5 to 2 px at final size),
  rounded corners on boxes, generous white space. Publication style, not
  marketing style: no drop shadows, no gradients on the boxes, no 3-D bevels,
  no photographic texture, no glow. The underwater scene may use a soft
  vertical gradient; nothing else may.

  Typography: one clean sans-serif throughout (Inter, Source Sans, Helvetica).
  Band headers in small caps or all caps, ~11 pt equivalent. Labels ~9 pt
  equivalent. Every label must be legible when the image is 1328 px wide.
