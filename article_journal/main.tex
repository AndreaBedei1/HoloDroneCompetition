\begin{abstract}
Autonomous racing provides repeatable end-to-end tests for perception, planning
and control, yet underwater robotics lacks a comparable contract for ordered
gate navigation. We present \mra{}, a configurable benchmark and evaluation
framework for onboard-only autonomous underwater gate racing, implemented over a
HoloOcean backend with a BlueROV2-class vehicle. The benchmark fixes the course,
observation boundary and scoring rules while separating autonomy from evaluation:
controllers receive only allow-listed onboard measurements, packets delivered
through a simulated/modeled acoustic channel and optional teammate messages,
whereas an independent referee
uses privileged simulator state to validate crossings, apply penalties and
produce machine-readable outcomes. The same contract supports onboard gate
perception and acoustic--visual association, interpretable reference controllers,
multi-vehicle scoring and a learning-integration path. In a 78-run systematic
evaluation, the framework exposes controller differences across circuits,
currents and fleet configurations; in a separate current-free demonstration, the
reference controller completes all three circuits in 9/9 runs without collision,
out-of-bounds or wrong-direction events. Currents discriminate robustness even
when clean-track completion is identical. A matched learning evaluation further
shows that learned policies can handle short gate transitions but currently lose
reliability when those transitions must be chained over full circuits. These
results position \mra{} as a reproducible evaluation instrument whose central
contribution is the common information boundary and independent referee, rather
than a particular control algorithm.
\end{abstract}
